# GOJ Web

当前已实现全站 AppShell、题目列表页，以及独立的登录和注册页面。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认运行在 `http://localhost:5173`，并将 `/api` 请求代理到 `http://localhost:8080`。

如需使用其他后端地址，可设置：

```bash
VITE_API_BASE_URL=http://localhost:8080
```

## 已实现范围

- 双层导航与固定右侧栏槽位。
- 游客和登录用户页头差异。
- 题目分页列表、关键词、难度、标签和做题状态筛选。
- Loading、Empty、Error 状态。
- 窄屏筛选抽屉、折叠菜单和横向滚动题目表格。
- 独立 AuthShell、真实登录注册接口、登录来源页返回和认证状态恢复。
- 注册页邮箱验证码保留为不可用占位，不发送 Mock 请求。
- 认证页面在窄屏下保持桌面布局，通过横向滑动查看完整内容。
- Markdown 题目详情、题目上下文侧栏和题目页签导航。
- CodeMirror 高亮提交编辑器、动态语言列表和真实提交接口。
- 我的提交列表、公开提交详情，以及进行中状态自动轮询。

比赛等页面当前仍只保留路由占位，不包含业务实现。
